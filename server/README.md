# Backend futuro

Esta pasta reserva um espaço para uma eventual aplicação backend do Dojo Kenpo Porto Alto. Ainda não contém API, servidor, dependências, autenticação, armazenamento ou configuração de serviços.

Só deverá ser implementada quando existir uma necessidade concreta que o frontend não possa resolver sozinho. A escolha de tecnologia e a definição das interfaces entre `client/` e `server/` ficam para essa fase.
